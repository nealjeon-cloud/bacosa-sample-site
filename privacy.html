개인정보처리방침

이 문서는 NEWFIND가 운영하는 내부 도구 "NEWFIND YouTube"(이하 "도구")가 Google 계정 정보를 어떻게 다루는지 설명합니다. 시행일: 2026-10-24.

1. 도구가 하는 일

도구는 운영자 본인이 소유한 YouTube 채널의 분석 숫자(조회수, 평균 시청 시간, 시청 지속률, 썸네일 노출수와 클릭률)를 하루 한 번 읽어 와 내부 대시보드에 기록합니다. 다른 사람의 계정이나 채널에는 접근하지 않습니다.

2. 요청하는 권한

  • YouTube Analytics 읽기 전용(yt-analytics.readonly)
  • YouTube 계정 읽기 전용(youtube.readonly)

도구는 동영상을 올리거나 지우거나 바꾸지 않습니다.

3. 저장과 공유

읽어 온 숫자는 운영자의 비공개 저장소와 내부 대시보드에만 저장합니다. 제3자에게 팔거나 넘기지 않으며, 광고에 쓰지 않습니다. 인증 정보(갱신 토큰)는 운영자의 서버에 접근 권한을 제한한 파일로만 보관합니다.

4. Google API 서비스 사용자 데이터 정책

도구가 Google API로 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Limited Use 요구 사항을 포함한 Google API Services User Data Policy를 따릅니다.

5. 권한 철회

Google 계정의 "보안 → 서드 파티 앱 및 서비스"에서 언제든 도구의 접근 권한을 철회할 수 있습니다. 철회하면 도구는 더 이상 숫자를 읽지 않습니다.
